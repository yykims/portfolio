K뷰티 아마존 리스팅 역기획

미국 아마존에서 팔리는 K뷰티 브랜드 하나를 골라, 상품 페이지를 다시 설계하고 채널별 수익 구조를 역기획합니다.

가정: ① 실제 판매 없이 공개된 정보만으로 진행한다 ② 대상 브랜드는 아직 정하지 않았다 ③ 수수료 · 비용 숫자는 아마존 공식 자료로 확인한 뒤 채운다

왜 하나

K뷰티 해외 채널 · 글로벌 마케팅이라는 판이 저에게 맞는지 검증하고, 가장 부족한 '돈이 벌리는 구조를 보는 힘'을 직접 계산하며 익히려 합니다. 돈이 들지 않는 대신 실제 판매 데이터는 없습니다.

무엇을 하나

  1. 리스팅 진단 — 메인 · 서브 이미지, A+ 콘텐츠, 상품명 · 불릿을 분석하고, 리뷰에서 반복되는 불만과 칭찬을 정리합니다.
  2. 수익 구조 역기획 — 판매가에서 아마존 판매 수수료, 배송 대행(FBA) 비용, 광고비, 원가를 빼면 얼마가 남는지 한 장으로 계산합니다. [확인 필요: 뷰티 카테고리 수수료율 · FBA 요금 — 아마존 셀러 센트럴 공식 요금표]
  3. 개선안 제작 — 진단을 근거로 메인 + 서브 이미지 7장, A+ 콘텐츠 1건, 15초 숏폼 소재 3종을 다시 만듭니다.
  4. 작은 검증 — 기존 이미지와 개선 이미지를 나란히 보여 주고 어느 쪽을 클릭하고 싶은지 묻는 선호 테스트를 20~30명에게 진행합니다.

산출물

  • 리스팅 진단 리포트 1장 · 수익 구조 계산표 1장
  • 개선 이미지 세트 · A+ 콘텐츠 · 숏폼 소재 3종
  • 선호 테스트 결과와 회고

확인받고 싶은 것

실제 판매 없이 만든 역기획이 이 판에서 의미 있는 증거가 될 수 있을지, 아니면 작은 금액이라도 직접 팔아 보는 편(초안 ②)이 나을지 여쭙고 싶습니다.
